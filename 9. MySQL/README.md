# SQL 실습 및 학습 가이드

## 📚 개요
이 폴더는 MySQL 데이터베이스 학습 및 실습을 위한 SQL 스크립트 모음입니다. 다양한 SQL 기능과 명령어를 연습하고 이해할 수 있는 자료들이 포함되어 있습니다.

## 🗂️ 파일 목록 및 설명

### 기본 명령어 및 실습
- `Mysql 명령어 실습.sql`: MySQL의 기본 명령어와 데이터베이스 조작 방법
- `Mysql DB생성.sql`: 데이터베이스 및 테이블 생성 스크립트
- `sql이해.sql`: SQL 기본 개념 및 쿼리 이해를 위한 예제

### 집계/조인 등 고급 쿼리
- `Mysql 내장집계함수.sql`: 데이터 집계를 위한 내장 함수 실습
- `Mysql 조인함수.sql`: 테이블 조인 방법과 실습 예제
- `조인연습.xlsx`: 조인 연습을 위한 추가 데이터 시트

### 기타 실습 파일
- `sqltest.sql`: 다양한 SQL 기능 테스트를 위한 스크립트
- `train.sql`: 추가 학습 및 연습용 SQL 스크립트

## 🚀 학습 경로 추천
1. `sql이해.sql`로 기본 개념 학습
2. `Mysql 명령어 실습.sql`로 기본 명령어 연습
3. `Mysql 내장집계함수.sql`로 데이터 분석 함수 학습
4. `Mysql 조인함수.sql`로 조인 및 다중 테이블 활용

## 💡 사용 팁
- 실습 전 MySQL Server 및 클라이언트를 설치하세요.
- 스크립트는 학습 목적으로 작성되었습니다. 운영 환경 적용 시 주의가 필요합니다.
- 데이터베이스 및 테이블 생성 시 기존 데이터에 덮어쓰지 않도록 주의하세요.
