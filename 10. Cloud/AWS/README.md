# 🚀 AWS(Amazon Web Services) 배포 및 운영 가이드

이 폴더는 AWS 클라우드 환경에서 인스턴스 생성, 서버 배포, 주요 설정 절차를 실제 이미지와 매뉴얼로 담고 있습니다.

## 📁 폴더/파일 구조
- [AI마스터]클라우드와MLOps.pdf : 전체 운영 및 배포 흐름 공식 매뉴얼(PDF)
- 1~5. AWSEC2.png, AWSconfig.png, AWSkey.png : 단계별 실습 화면 캡처(EC2 인스턴스 생성, Key 관리, 보안 설정 등)
- main.py : FastAPI 예제 서버 코드
- templates/index.html : 실제 서비스 템플릿 예시

## 📝 활용 및 참고
- AWS EC2 배포 설정, 서버 키관리 등 기초부터 실전까지 전과정 이미지로 파악 가능
- FastAPI 등 실습 코드 참고: main.py, templates/index.html
- 공식 PDF 매뉴얼에서 전체 흐름 및 배경을 상세히 확인 가능
